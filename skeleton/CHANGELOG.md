# 更新日志

## 2026-11-17 无单位阵营死锁修复

- **问题**：阵营只剩基地、没有单位时，既不能采集，也买不起下一个单位，基地永远不再出兵。10 人局 15 局模拟中，空窗记录 109 个，仅 3 次恢复。
- **修复**：`baseProduce` 在阵营单位数为 0 且买不起时，免费出一名工人；有单位时仍按原价出兵，满编上限和无基地不出兵的判断不变。
- **效果**：同口径重测 15 局，恢复次数 3 → 594，空窗超过 30 秒的阵营数为 0。
- **测试**：`test:logic` 新增 3 组，九组测试全部通过。
- **提醒**：24 个采集点中有 4 个（金矿、铁矿各 2 个）在矿洞占地内，做避障寻路前需先挪开。

## 2026-11-08 启动排障与逻辑收口

- **端口冲突**：`8080` 被其他程序占用时，服务端打印明确的换端口命令而不是抛 `EADDRINUSE` 堆栈；`/health` 增加 `game` / `port` 标识，启动页 404 时提示端口可能被占。客户端 WebSocket 跟随 `location.host`，换端口无需改代码。
- **人数与出生点**：真人上限 10（等于出生点数）；出生点按占位索引分配，第 11 人被明确拒绝，投降释放的位置可安全复用。对局中加入真人时，一个补位 AI 会让位。
- **阵营合并**：加入阵营时统一迁移库存、积分、粮食欠账、资源点归属、在途箭矢与全部实体；合并链指向最终根阵营；禁止循环合并、重复合并、加入自己或已投降阵营。并入方共享胜负，本窗口不再直接指挥。
- **掉线重连**：断线不再立即判负。解除化身、单位继续 AI 自治，60 秒内用浏览器持久 `clientId` 自动重连即可恢复原阵营；超时才出局。同一身份在别的窗口登录会收到明确提示。
- **采集校准**：采集改为按真实决策间隔累积小数，工人 6/s、战士 2/s 与配置一致；同时修复 AI 思考计时的浮点误差（`0.2` 曾被拖成 `0.25` 秒）。采集变紧后早期对抗更激烈，平衡数值待单独校准。
- **状态包瘦身**：常量 `rules` 改为 `welcome` 一次性下发，坐标压缩到 2 位，渲染层不用的动画字段与默认值字段不再每帧发送，`factions.alive` 改为一次性集合计算。满员（10 阵营 / 80 单位）单帧 26.3 KB → **16.0 KB**，10 人服务端出站约 5.1 → **3.1 MB/s**。
- **测试**：`test:logic` 新增 7 组确定性断言（出生点、AI 让位、合并、速率、状态包），`test:network` 新增 welcome 规则、掉线重连与满员拒绝断言。`test.js` 的指令类断言改到独立短局并固定随机序列，不再受随机战况影响。九组测试全通过。
- **仍未做**：浏览器 GPU 视觉验收、途中避障寻路、客户端预测/外推、增量同步与视野裁剪。

## 2026-10-28 瞄准与建造修正

- **单击接管与移动**：单击己方单位或部队按钮即接管其行动，保持俯视；再点击地面前往该点，途中可重新点击改道。每次有效点击显示小红旗 1 秒，随后自动消失；改道时更新位置并重新计时。单位到达后原地待命。框选部队同样支持点击移动；点击敌方目标仍为攻击。
- **目的地限制**：禁止选择地图边界外、树木、岩石、矿洞、风车、围栏、建筑与资源点占地；点击树冠或屋顶也不会穿透成后方地面指令。无效点击提示原因，保留原指令且不刷新红旗。客户端与服务器共用场景位置和占地规则，林间空地可选。本次为目的地点校验，尚未加入途中避障寻路。
- **恢复职位**：H 回家后自动解除接管，恢复原兵种工作；X /「自动行动」立即解除接管。接管本身不增加生命或攻击，双击 / P 进入 3D 化身时才有化身加成。接管工人会交接施工，工地不会自动抢回该工人；主动确认建造可重新派遣。
- 验证：`npm run test:input`、`npm run test:squad`、`npm run test:scene`、`npm run test:network`。
- **左键框选**：在俯视地图中按住左键拖动，松开选择框内己方单位；Shift 框选追加，Shift 单击增减选中单位。选中的所有单位显示金色圈。
- **部队攻击**：选中后点击敌人，或按 A /「攻击目标」再点敌人，对选中部队统一下达追击攻击指令；X 批量取消。
- **回家**：按 H /「回家」，每名选中单位返回最近的己方基地。到达后上缴携带资源、清除手动指令，并按原兵种恢复 AI 行为；兵种不变。若目标基地失守，改回其他己方基地。
- 框选仅用于俯视指挥，箭塔选址仍保持单击锁定、双击建造。双击己方单位或 P 仍可化身。

- 准心跟随鼠标在游戏画布内的位置，挥击和箭矢方向使用同一条鼠标射线；右键拖动仍用于转动镜头。鼠标移入界面面板时隐藏准心并停止发出攻击输入。
- 选址预览不扣金币、木材。选址期间暂时停止己方基地自动出兵，保护建塔预算；取消、放置成功或选址连接超时后恢复。
- 只有服务端通过位置、范围、工人和资源校验并成功放置工地，才扣 15 金币与 30 木材。失败不扣，重复提交同一次确认不重复扣费。
- 箭塔只能放在己方任意基地周围 18 格内，且距离建筑基地至少 6 格。预览显示外围范围圈和基地内圈；仍需避开资源区、河道与已有建筑。

## 2026-10-27 地图与视角更新

### 自然恢复与工人施工

- 人物处于受伤状态时，每累计 10 秒恢复当前最大生命的 1%；不要求脱战，不会超过上限。化身加成计入最大生命，建筑不享受自然恢复。
- 按 B /「建造箭塔」进入俯视选址，单击地图锁定位置，锁定后鼠标移动不再改变坐标；再次单击可换位置。双击或点击「确认施工」派工，Esc /「取消」退出选址。绿色表示可施工，红色会说明原因。
- 确认后扣除 15 金币和 30 木材，优先派遣选中的可用工人，否则派最近的可用工人。无工人、资源不足或位置无效时不扣费。
- 工人抵达后施工 12 秒，赶路时间另计。工地显示脚手架、建筑成长、进度条和剩余时间，完工前没有攻击能力；工人施工时播放敲击动作。
- 化身接管、攻击指令或工人阵亡会中断该工人的施工，工地保留进度并自动寻找可用工人接替。左下角施工列表可取消，按未完成比例退还金币和木材（向下取整）。
- 工地可被攻击摧毁；受损工地完工时保留生命比例。施工地点不能占用河道、森林、矿场、农田、资源点或重叠已有建筑。
- 验证：`npm run test:construction`、`npm run test:scene`、`npm run test:network`。

### 战斗操作更新

- **俯视指挥**：单击己方单位或部队按钮选中，再左键或右键点击敌方单位、基地、箭塔，下达追击攻击指令。金色圈标识选中单位，橙色圈标识目标；X /「取消攻击」恢复自动行动。
- **进入化身**：双击己方单位，或选中后按 P /「化身单位」；化身中 P 轮换单位，Esc 返回俯视。
- **空格攻击**：战士挥剑、工人挥镐，空挥也播放动作。射手先拉弓 0.38 秒再放箭，箭矢沿瞄准方向飞行，由服务端判定命中。
- **准心**：化身后准心跟随鼠标移动，右键拖动转动镜头；敌人在射程内时准心变色，拉弓时显示蓄力进度，放箭后显示冷却。射手射程调整为 18。
- **化身加成**：攻击力、最大生命及当前生命按比例增加 20%，保留原有移速 +15%。退出时恢复原生命上限并保留生命百分比，重复切换不会回血或叠加；例：战士 150 → 180 血，18 → 21.6 攻击。
- 验证：`npm run test:combat`、`npm run test:scene`（CPU 场景几何与姿态，不代替 GPU 视觉验收）、`npm run test:network`。

- 操作文案统一使用「化身」。启动页显示真实阶段进度、百分比和已用时间，只有地图完成首次绘制并连上服务才允许进入。
- 启动时检查服务版本与本地 3D 引擎；旧服务、缺失依赖、模块错误和连接失败均显示处理提示。超过 30 秒停止等待，可点击重新加载。
- 卡在旧版「准备地图」通常需要重启仍在运行的旧 Node 服务；新页面会明确提示，不再无限等待。
- 启动回归测试：`npm run test:startup`。

- 地图升级为本地 Three.js 渲染的低多边形河谷：松林、铁矿、金矿、农田、风车、营地、河流、木桥与外围山石。
- 8 个资源区域、24 个真实采集点；客户端和服务端共用 `client/world.js`，资源位置一致。
- 默认为俯视地图。单击选择部队，双击单位或按 P 切换为第三人称 3D 化身；Esc /「俯视地图」退出化身并恢复 AI。
- 化身时 WASD / 方向键相对镜头移动，空格攻击，右键拖动环视，滚轮调整跟随距离。
- 俯视时滚轮缩放、右键拖动平移；点击右下角小地图定位。
- 新增资源栏、部队面板、阵营战况、操作按钮；对局结束后可以点击「开始下一局」，所有在线玩家进入新局。
- 修复采集资源上缴未正确入账；固定基地出生点，防止开局贴脸；初始包含工人、战士和射手。
- 当前河流可涉水通过，树木、山石为场景装饰，尚未加入障碍碰撞和寻路。
- 需要支持 WebGL 2 的桌面浏览器。Three.js 固定为 0.180.0 并从本地依赖提供，游玩时无需访问外部 CDN。
