# PRD：火柴人领地（V1 · 已确认版）

> 版本：V1 · 状态：方案已确认，可进入骨架
> 本文件按 agent-blueprint 手册维护，升版由 `revise` 流程产生，旧版存 `prd/V*.md`

## 1. 一句话目标

火柴人俯视视角联机对战：基地生产不同角色，玩家采集「金币 / 粮食肉类 / 木材 / 矿产」四类资源、扩张领地、抢占敌方基地；玩家可随时「化身」任意己方角色亲自操控作战（化身时该角色由人工接管并获得临时 BUFF，脱离即失效）。一局结束条件（任一先达成即结束）：**消灭所有敌人 / 所有敌人投降 / 倒计时结束积分最高**。

## 2. 用户与使用方式

| 项 | 内容 |
|---|---|
| 目标用户 | 联机对战玩家 |
| 交互形态 | 实时同步，俯视视角 |
| 每局人数 | 2~10 人自由混战；人数不足自动补 AI |
| 平台 | PC，Unity 客户端 |
| 时限 | **7 天内上线**（硬约束，一期范围按此裁剪） |

## 3. 核心闭环（一次完整对局）

基地生产角色 → 角色 AI 自治采集四类资源 / 玩家化身关键角色亲自操作 → 建造/升级单位与设施 → 争夺中立资源点与敌方基地 → 敌方被消灭 / 投降 / 加入己方阵营 / 时间到 → 按积分结算胜负。

## 4. 交付物

- 一个可游玩的 Unity 联机对战游戏（俯视 2D 火柴人）。
- 每局产出积分榜与胜负判定。

## 5. 边界（一期明确不做）

- 不做单机剧情 / 战役、账号系统、云存档、商城、技能树、移动端。
- 联机先做 Host 权威 + 直连建房（7 天约束），专用服务器与反作弊二期。

## 6. 已确认项（回答记录）

1. **单位来源**：基地生产不同角色（兵种），玩家选一个化身；未被化身的角色由 AI 自治。（修正了"带 AI 小弟"的表述）
2. **每局人数**：2~10 人，不足自动补 AI。
3. **化身**：随便切；被化身角色由人工接管；化身加临时 BUFF（默认仅化身期生效、脱离即消失，无冷却）。
4. **胜利**：消灭所有敌人 / 所有敌人投降 / 倒计时结束积分最高，任一先达成即结束。
5. **投降 / 加入对方阵营**：手动按钮。投降 = 出局；加入对方阵营 = 并入对方阵营共享胜负。
6. **时限**：7 天内上线。

## 7. 待确认项（按默认假设实现，可随时改）

1. **单局时长**：默认 10 分钟。
2. **积分权重**：击杀普通单位 +10 / 击杀被化身单位 +30 / 拆基地 +100 / 占领资源点 +2 每秒 / 结余资源 1/100 折算。
3. **化身 BUFF 数值**：攻击 +20%、移速 +15%（仅化身期）。
4. **「消灭」判定口径**：默认「敌方基地被拆毁且无存活单位」= 该阵营出局。
5. **地图**：默认中等地图 + 散布中立资源点 + 中立野怪（掉落粮食肉类）。
6. **网络框架**：默认 Mirror（host 权威 + 直连建房）。
